# Sonic Player

A sleek, responsive music player for your personal audio library. Built with vanilla HTML, CSS and JavaScript.

![Sonic Player](https://dummyimage.com/1200x630/111521/a18bff&text=Sonic+Player)

## Features

- Import multiple audio files directly from your device
- Play, pause, skip and go back between tracks
- Seek through tracks and control playback volume
- Shuffle and repeat playback modes
- Search your music library
- Like tracks and browse your favorites
- Create playlist labels
- Responsive layout for desktop and mobile
- Keyboard shortcuts: **Space** to play/pause and **Ctrl/⌘ + K** to search
- No account, backend or API key required

## Run locally

1. Clone this repository:
   ```bash
   git clone https://github.com/akhil-axv/qwerftgjkl.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
4. Select **Add music** and choose audio files from your device.

You can also use a local development server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- HTML Audio API

## Privacy

Audio files are played locally in your browser. This project does not upload your music to a server.
